# Web Development

This folder contains the main topics, practice tasks, and projects related to **web development**.

Web development is divided into three main parts: **Frontend, Backend, and Database**.

## 📂 Folders

### Frontend

Frontend is the part of a website that users can **see and interact with**.

It includes:

* HTML — Structure of web pages
* CSS — Design and styling
* JavaScript — Logic and interactions
* Projects — Complete frontend projects

### Backend

Backend handles the **server-side work** of a website.

It includes:

* Server-side programming
* REST APIs
* Authentication
* Business logic
* Backend practice and projects

### Database

Database is used to **store and manage application data**.

It includes:

* **Supabase** — Backend and database platform
* **Sequelize** — ORM for SQL databases
* **Mongoose** — ODM for MongoDB
* Database concepts, queries, and practice

## 🎯 Goal

The goal is to understand **Frontend, Backend, and Database** step by step and use them together to build complete web applications.
