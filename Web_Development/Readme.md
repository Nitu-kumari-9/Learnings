# 🌐 Web Development

This folder contains the main topics and practice work related to web development.

Web development is divided into two main parts:

- Frontend
- Backend

Backend also includes database technologies and database concepts.

---

## 📂 Folders

### Frontend

Frontend is the part of a website that users can see and interact with.

It includes:

- HTML — Structure of web pages
- CSS — Design and styling
- JavaScript — Logic and interactions
- Projects — Complete frontend projects

---

### Backend

Backend handles the server-side work of a web application.

It includes:

- Server-side programming
- REST APIs
- Authentication
- Authorization
- Business logic
- Node.js
- Express.js
- Database
- Backend practice

#### Database

Database is used to store and manage application data.

It includes:

- SQL — Relational databases
- Sequelize — ORM for SQL databases
- MongoDB — NoSQL database
- Mongoose — ODM for MongoDB
- Database concepts, queries, and practice

---

## 🎯 Goal

The goal is to learn web development step by step and understand how Frontend, Backend, and Database work together to build complete web applications.
