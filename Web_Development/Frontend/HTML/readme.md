## HTML Practice and Notes

What this folder is for
- Learn HTML step by step.
- Save short notes, simple examples, and small tasks to practice.

What's inside
- `html.md` — main notes with simple explanations.
- `Notes/` — extra topic notes and code snippets.
- `Task/` — practice tasks and exercises to try yourself.

How to use this folder (easy steps)
1. Read a short note in `html.md` or in `Notes/`.
2. Try the examples in a browser to see how they work.
3. Do a task from `Task/` to practice what you learned.
