# Frontend

This folder contains **frontend learning notes, practice tasks, and projects**.
The content is organized into different folders for each part of frontend development.

## 📂 Folders

* **HTML** — Contains HTML notes, practice tasks, and examples for learning page structure and basic web elements.

* **CSS** — Contains CSS notes and chapter-wise practice tasks for styling and designing web pages.

* **JavaScript** — Contains JavaScript concepts, examples, and practice tasks for adding logic and interactivity to web pages.

* **Projects** — Contains complete frontend projects created using HTML, CSS, and JavaScript.

The goal is to **learn frontend development step by step through concepts, practice, and projects**.
