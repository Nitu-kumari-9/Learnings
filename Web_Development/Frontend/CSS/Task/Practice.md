# 📘 Chapter 1 – Introduction to CSS

## 🎯 Task: Style a Simple Webpage

### Create a webpage with:
- 📝 One Heading
- 📄 One Paragraph
- 🔘 One Button

- ✅ Inline CSS

# 🚀 Learning Flow

```text
Chapter 1 → Style a Simple Webpage
        ↓
Chapter 2 → Student Information Page
        ↓

        ↓
```

> 💡 **Tip:** Don't create a new project for every chapter. Keep improving the **same project** after each chapter. This is how real frontend developers learn and build projects.
