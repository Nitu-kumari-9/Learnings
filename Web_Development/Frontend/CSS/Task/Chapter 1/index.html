My First Styled Page

This heading above is styled using Internal CSS (written in a <style> tag).

This paragraph is styled using External CSS (from style.css).

This paragraph is styled using Inline CSS (written directly in the style attribute).

CSS can be written in three places, and all three are shown on this page:

  • Inline — inside the element's own style attribute.
  • Internal — inside a <style> tag in the <head>.
  • External — inside a separate .css file, linked with <link>.
