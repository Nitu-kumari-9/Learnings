# Nexa Smart Home Landing Page

A smart home product landing page built using HTML and CSS.  
This project practices CSS concepts from Chapter 1 to Chapter 7.

## Tasks
- [ ] Create a header and product section.
- [ ] Design a smart home device using HTML and CSS.
- [ ] Add product price and feature cards.
- [ ] Practice colors, backgrounds, borders, and box model.
- [ ] Use `px`, `%`, `em`, `rem`, `vw`, and `vh` units.
- [ ] Resize the browser and observe how different CSS units behave.
