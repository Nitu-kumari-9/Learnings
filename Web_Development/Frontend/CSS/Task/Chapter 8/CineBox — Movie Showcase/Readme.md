# Retro Film Club

A vintage-style movie showcase website built using HTML and CSS.  
This project practices CSS concepts from Chapter 1 to Chapter 8.

## Tasks
- [ ] Create a header with logo and navigation.
- [ ] Design a vintage-style hero section.
- [ ] Display three movie posters with details and ratings.
- [ ] Use `block`, `inline`, and `inline-block`.
- [ ] Practice borders, backgrounds, fonts, spacing, and sizes.
- [ ] Create an About section and footer.
- [ ] Use only HTML and CSS without Flexbox, Grid, or Position.
