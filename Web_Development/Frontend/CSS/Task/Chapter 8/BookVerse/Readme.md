# BookVerse — Online Book Store

A simple online bookstore website built using HTML and CSS.  
This project practices CSS concepts from Chapter 1 to Chapter 8.

## Tasks
- [ ] Create a header with logo and navigation.
- [ ] Design a hero section with a heading and button.
- [ ] Display three book cards with images, titles, authors, and prices.
- [ ] Practice `block`, `inline`, and `inline-block`.
- [ ] Use `vertical-align` to align book cards.
- [ ] Style backgrounds, colors, borders, spacing, and fonts.
- [ ] Create an About section and footer.
- [ ] Use only HTML and CSS, without Flexbox, Grid, or Position.
