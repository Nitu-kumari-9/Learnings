## Chapter Cheat Sheet

| Property | Easy Hinglish |
|---|---|
| `@keyframes` | Animation ke steps batata hai. |
| `animation-name` | Kaunsi animation chalani hai. |
| `animation-duration` | Animation ko kitna time lagega. |
| `animation-delay` | Shuru hone se pehle kitna wait karna hai. |
| `animation-iteration-count` | Animation kitni baar chalegi. |
| `animation-direction` | Animation aage chalegi ya wapas bhi aayegi. |
| `animation-timing-function` | Animation ki speed kaise badlegi. |
| `animation-fill-mode` | Animation ke baad style kaisi rahegi. |
| `animation` | Multiple animation properties ko ek line mein set karta hai. |

**Remember this syntax:**

```css
animation: name duration timing-function delay
          iteration-count direction fill-mode;
```

**Final Reminder:** `@keyframes` animation ke steps define karta hai, aur `animation` property us animation ko element par chalati hai.
