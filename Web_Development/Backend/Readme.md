# 🧠 Learning Method

Each topic should be learned through:

### 1. Concept

What is it?

### 2. Why?

Why do we need it?

### 3. How?

How does it work?

### 4. Code

Write the code yourself.

### 5. Run

Execute the code.

### 6. Output

Understand the result.

### 7. Practice

Solve exercises based on the concept.

### 8. Common Mistakes

Understand mistakes developers commonly make.

### 9. Best Practices

Learn how to use the concept properly in real applications.
