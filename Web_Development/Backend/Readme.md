# ⚙️ Backend Development

This folder contains the concepts and practical learning materials required to understand backend development using JavaScript.

The content starts from backend fundamentals and gradually moves toward advanced backend development.

---

## 📂 Topics

### 01. Backend Fundamentals

Learn the basic concepts of backend development.

- Backend
- Client–Server Architecture
- HTTP & HTTPS
- Request & Response
- JSON
- APIs
- REST API

### 02. JavaScript for Backend

Learn the JavaScript concepts required for backend development.

- JavaScript Fundamentals
- Functions
- Arrays & Objects
- Modules
- Callbacks
- Promises
- Async/Await
- Error Handling
- Event Loop

### 03. Node.js

Learn how JavaScript works on the server.

- Node.js
- Node.js Architecture
- Event-Driven Architecture
- Non-Blocking I/O
- Core Modules
- File System
- Streams
- Events
- npm
- Environment Variables

### 04. Express.js

Learn how to build backend applications and APIs with Express.js.

- Express Server
- Routes
- Request & Response
- Route Parameters
- Query Parameters
- Request Body
- Middleware
- Router
- Error Handling
- Project Structure

### 05. REST API

Learn how to design and build REST APIs.

- REST
- REST Principles
- HTTP Methods
- Status Codes
- Headers
- CRUD APIs
- Validation
- Pagination
- Filtering
- Sorting
- Searching
- API Versioning
- API Documentation
- API Testing
